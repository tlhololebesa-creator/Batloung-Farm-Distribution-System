
# Batloung Farm Distribution System

## Project Description

The Batloung Farm Distribution System is a web-based application developed to manage the daily operations of a fruit distribution business. It helps manage suppliers, fruits, vendors, purchases, sales, stock and payments.

## System Features

- Dashboard displaying business summaries.
- Supplier management.
- Fruit management.
- Vendor registration and management.
- Stock management by packaging size.
- Purchase management.
- Sales management.
- Payment management.
- Sales reports and business summaries.
- Automatic stock updates.
- Tracking of vendor outstanding balances.

## Technologies Used

### Frontend
- React
- Vite
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MySQL2
- MySQL
- REST API

## Database

The system uses a MySQL database named `batloung_farm`.

The database manages suppliers, fruits, vendors, purchases, purchase details, sales, sales details, stock and payments.

## Project Structure

- `src/` - Frontend source code.
- `backend/` - Backend application.
- `backend/config/` - Database configuration.
- `backend/controllers/` - Request handling.
- `backend/models/` - Database operations.
- `backend/routes/` - API routes.
- `backend/middleware/` - Error handling.

## Running the Project Locally

### Frontend

1. Open the project folder in VS Code.
2. Install dependencies:

   `npm install`

3. Start the frontend:

   `npm run dev`

### Backend

1. Open the backend folder.
2. Install dependencies:

   `npm install`

3. Configure the database credentials in the backend `.env` file.
4. Start the backend:

   `node server.js`
